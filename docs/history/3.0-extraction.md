# 3.0 extraction

This repository extracts the immutable-generation store, focused tests,
manuals, and `pkgstate-check` from `libpkgstate` commit
`ffb22c42768b317ade0c406fdb563a63708c148a`. The repository extraction
preserves compare-and-publish semantics. The accompanying source-authority
reset advances durable storage from generation v3 to generation v4 because
`libpkgsource` 3.0 retired recipe identity rather than reassigning its meaning.
